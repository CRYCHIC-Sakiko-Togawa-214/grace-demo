# Security policy

This repository serves a static research demonstration. It does not require credentials
for viewing or local preview. The bundled preview server is a development tool;
keep its default loopback address and use a static hosting service for public access.

For a security concern, use GitHub's **Report a vulnerability** entry in the Security
tab if available. Otherwise contact the repository owner privately through a contact
listed on their GitHub profile. Do not post secrets, unpublished data, or exploit
payloads in a public issue. Ordinary playback or missing-file problems belong in
the repository issue tracker.
